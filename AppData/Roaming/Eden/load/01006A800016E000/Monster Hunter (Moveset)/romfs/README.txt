Monster Hunter joins the battle!
This is a complete moveset including Final Smash, Classic Mode route, and fighter tips entries.
Please see the in-game fighter tips for information on her moves.

== Dependencies ==
You must have these plugins installed for the mod to work:
- Smashline 2 (1.6.4 or newer) - https://github.com/HDR-Development/smashline/releases/latest
- ARCropolis - https://github.com/Raytwo/ARCropolis/releases/latest
- NRO Hook Plugin - https://github.com/ultimate-research/nro-hook-plugin/releases/latest
- The CSK Collection - https://gamebanana.com/mods/499008
- Param Config - https://github.com/CSharpM7/lib_paramconfig/releases/latest
- One Slot Effects - https://gamebanana.com/mods/549058

== Install ==
Simply drag the "Monster Hunter (Moveset)" folder into the /ultimate/mods folder on your SD card.
For emulator users: navigate to your emulator data folder, then go to sdcard/ultimate/mods.
